# v2 原型 NOTES

## 问题
v2 六步流程（受理→查询→明细→回复函→处理/配合度→归档）的界面应该长什么样？

## 打开方式
双击 `static/prototype/v2-demo.html`，或应用运行时访问 `/static/prototype/v2-demo.html`。

## 结论（已确认）
- **胜出布局：C 三栏工作台**（中央操作区 + 右侧学员档案/时间线常驻）。
- A 分步向导、B 单页纵览保留为切换参考，后续可删。

## 用户修订（8 项，全部已实现并验证）
1. 在途案件移至右栏「办理时间线」下方，默认折叠，点击展开切换案件。
2. 三系统查询结果改为 5 页签：基本信息 / 考试情况 / 培训学时 / 收费记录 / 学习时间轴；字段带来源标签（内部系统/东莞驾培），口径说明固定在底部。
3. 案件卡可读性重构：姓名+单位代号一行，小字身份证号、「投诉日期」（不再叫受理）、当前阶段。
4. 回复函改为：系统生成初稿（衬线体编辑器）→ 可直接改字 → 「✨一键AI修改」润色 → 「审阅无误，生成回复函」落盘到档案路径；支持重新编辑、预览、暂不写跳过。
5. 配合度图标改为形状区分：✓绿圆(好) / —黄圆(中) / ✕红圆(差)，看板明细同步。
6. 扣费明细表确认后显示「🔓解锁修改」，随时可重编，删除"联系管理员重开"限制。
7. 归档点击后先弹窗展示目标路径+材料清单，确认后写入并打开文件夹。
8. 新增「三系统并行查询」过程演示页（内部→第三→东莞驾培依次完成，驾培非精确匹配警示）；统计看板保留五模块+类型环图。

## 已验证（chrome-devtools 实测）
- 五页签内容渲染正确；明细编辑实时联动合计（2500→应退1180），确认/解锁状态机正确。
- 回复函初稿含姓名与金额 → AI润色替换文案 → 落盘后出现绿色文件路径 chip → 重新编辑可回退。

- 在途案件折叠展开正常，「未知校区」等无代号单位不再显示 undefined。
- 受理→查询模拟→自动进入工作台全链路无 console 错误。

2. 归档不再产出 Excel 明细表：仅「投诉登记表.docx + 投诉回复函.docx」两件；夹内文件命名简化为 `日期_姓名_文书类型.docx`（完整身份信息由案件夹名承载）。
3. 扣费明细表新增「👁 预览合同」：弹窗左侧合同条款原文、右侧扣费项对照，悬停/点击扣费项自动定位并高亮对应合同条款。
4. 取消归档二次确认弹窗：点击归档直接写入并打开文件夹。
5. 处理情况新增「✨ AI优化」：将随手记录整理为「核实诉求→说明依据→协商结果→后续跟进」四点式正式表述；手动编辑自动还原按钮。

7. 基本信息排版重做：双列固定对齐、标签定宽灰色、数值加粗统一字号、来源标签灰化不换行。
8. 扣费明细表金额列居中等宽字体显示。
