# 合同档位以权威数据推断，OCR 文本不作判据

上传合同（无驾培电子合同的学员）必须先确定**合同档位**才能算扣费：六档合同的违约金率相差三档（2019=0%、2021-2022=10%、2023=20%），必扣项相差 700 元（2023 分店多场地费）。纯靠 LLM/OCR 从扫描件认档位不可靠——「10%」与「20%」恰是 OCR 最易认错的字符，而认错的代价是几千元的应退差额。

决定：档位由**报名日期 + 网点类型（`org_unit_service` 的 分校/分店）**从系统已有权威数据推断出候选，再用合同文本**特征句**（引用《合同法》→2019；「协助报考服务费」→2021-2022；「建档费」「20%」→2023）做校验并给出置信度；最终以用户可改的下拉框呈现。OCR/LLM 抽取值（含 `penalty_rate`）一律只做**校验**：与档位默认值冲突时告警，不采信。

Considered Options：纯 OCR/LLM 识别（拒绝：错字即错钱）；用户每次手选（拒绝：多一步操作且失去校验锚点）。

Consequences：2021 与 2022 模板退费规则完全相同，合并为「2021-2022」一档，不逐年硬分；新增合同模板时需在档位表中登记特征句。
