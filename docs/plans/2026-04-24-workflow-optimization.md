# 投诉处理流程优化计划

## 问题分析

### 1. 时间轴显示问题
- 只有日期，没有事件内容
- 需要显示每个时间节点的具体操作

### 2. 处理操作流程混乱
当前：三个按钮并列，用户不知道先后顺序
应该：顺序流程，完成一步才能下一步

### 3. AI分析合同操作不直观
- 上传文件后不知道怎么操作
- 缺少明确的下一步指引

### 4. 手动填写字段不全
需要参考回复函和合同，提炼完整字段：

**回复函需要的数据：**
- 学员基本信息（姓名、身份证、驾校、报名日期、车型）
- 培训进度（当前阶段、各科培训时长）
- 费用信息（总费用、扣费明细、应退金额）
- 合同条款引用

**退费计算需要的数据：**
- 已缴培训服务费
- 各科培训学时（科二、科三）
- 考试阶段
- 扣费项目（服务费、理论费、实操费、违约金等）

## 实施步骤

### Task 1: 修复时间轴显示
- 修改 `query_service.py` 返回完整时间轴数据
- 修改前端显示时间轴事件内容

### Task 2: 重构处理操作流程
- 改为顺序流程：获取合同 → AI分析 → 生成回复函 → 提交飞书
- 每步完成后才显示下一步

### Task 3: 优化合同获取界面
- 三种方式：自动下载 / 上传文件 / 手动填写
- 上传后显示文件名和预览
- 手动填写包含完整字段

### Task 4: 优化AI分析界面
- 显示分析参数（培训时长、考试阶段）
- 可编辑的扣费明细表格
- 实时计算应退金额

### Task 5: 添加流程状态指示
- 当前步骤高亮
- 已完成步骤打勾
- 未完成步骤禁用
