# 三系统查询性能验收报告

验收日期：2026-07-01

## 结论

- 三系统仍保持并行查询，最终业务字段未减少。
- 内部系统会话在后台提前刷新，网络错误不再误触发验证码登录。
- 页面按系统渐进显示结果，首个系统完成后即可查看已返回信息。
- 三系统未完成前禁止进入合同扣费分析，避免使用不完整进度计算费用。
- 同一证件五分钟内重复查询命中内存缓存，后续查询耗时约为 `0s`。

- 两个重叠查询的标准化业务结果一致。
- 每个查询最后一次渐进结果与最终返回结果一致。
- 全量自动化测试：`98 passed`。
- 前端 JavaScript 语法检查通过。
- 浏览器加载、投诉受理入口、三系统查询入口正常，控制台无错误。

## 剩余限制

- 两个客户端同时查询同一证件时，当前为保护外部系统登录会话而按系统串行执行，其中一个请求可能延长到约 `10.6s`。
- 页面已禁止同一用户重复点击，因此日常单用户流程不受影响。
- 后续 P1 可增加“同证件在途请求合并”，但需要先验证跨请求共享渐进状态和任务失败恢复，不能直接并发复用同一爬虫会话。
- 东莞驾培健康查询主要耗时位于其单个外部接口（本轮 p50 `4.742s`），继续压缩需由对方接口性能或本地业务缓存策略解决。
