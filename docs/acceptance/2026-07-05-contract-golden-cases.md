# 真实合同黄金案例审计

**日期：** 2026-07-05
**用途：** 作为合同提取、规则计算和人工确认流程的业务验收基线。

## 统一口径

1. 合同只提取费用、勾选项和退费条款，不提取姓名、身份证、电话和签署日期。
2. 合同有效期从三系统报名时间起算三年。
3. 超过三年时必须提醒；只有合同明确约定到期不退，才将应退金额置为0。
4. 多份已签合同分别计算，再汇总合同金额、扣费和应退金额。
5. 内部系统状态决定已完成或已开始的合同阶段；考试次数只决定首次考试费和补考次数。
6. 缺页先提醒。用户未补页时，允许按现有清晰条款生成正式方案，但不得推测缺失条款。
7. 实际已交金额默认等于各份合同金额之和，处理人可以修改。
8. 每条扣费必须保存合同名称、条款依据、触发事实、公式和金额。

## 此前分析错误

1. 金凯悦900元被误识别成950元，科二250元被误识别成300元。
2. 金凯悦只按考试次数扣科一，遗漏“科二收”触发的科二阶段。
3. 谢婷合同明确到期不退，此前错误地按“无到期不退条款”处理。
4. 王家睿并非整份合同无法识别；规则字段可提取，只是最终金额所需字段不足。
5. 当前代码在未识别到违约比例时默认20%，会凭空产生扣费。
6. 当前代码只支持单合同总额，无法表达多份合同逐份计算及条款证据。
