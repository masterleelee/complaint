# 技术方案 - 投诉处理系统优化

## 1. 工单去重逻辑

### 需求
- 同一天同一人只保留最早的一条
- 重复投诉时更新最早记录

### 实现方案

**数据库层面 - 添加唯一约束**
```sql
-- 添加唯一索引：日期+身份证
CREATE UNIQUE INDEX idx_unique_daily_complaint 
ON complaint_tickets(date(complaint_date), id_card);
```

**保存时逻辑**
```python
def save_ticket_unique(data):
    # 1. 检查同一天是否已有记录
    existing = find_by_date_and_id(data['complaint_date'], data['id_card'])
    if existing:
        # 2. 更新最早记录
        return update_ticket(existing['id'], data)
    else:
        # 3. 新建记录
        return insert_ticket(data)
```

**利弊**
- ✅ 数据库层面保证唯一性
- ✅ 自动去重，无需前端处理
- ⚠️ 需要处理冲突（UPDATE 替代 INSERT）

## 2. 代号下拉框修复

### 问题
- 标签写"代号"，但实际绑定校区
- 需要显示真正的代号（school_short）

### 实现

**后端 API**
```python
@app.route("/api/school-codes", methods=["GET"])
def api_school_codes():
    """获取所有代号列表"""
    codes = get_distinct_school_short()
    return _ok(codes)
```

**前端修改**
```javascript
// 加载代号列表
const schoolCodes = ref([]);
async function loadSchoolCodes() {
    const res = await fetch('/api/school-codes');
    schoolCodes.value = await res.json();
}

// 下拉框
<select v-model="schoolFilter">
    <option value="">全部</option>
    <option v-for="code in schoolCodes" :value="code">{{code}}</option>
</select>
```

## 3. 仪表盘图表（飞书风格）

### 技术选型
- **ECharts** - 功能丰富，可定制

### 图表规划

| 图表 | 类型 | 数据 |
|------|------|------|
| 本月投诉 | 数字卡片 | COUNT(*) WHERE 本月 |
| 累计投诉 | 数字卡片 | COUNT(*) |
| 待处理 | 数字卡片 | COUNT(*) WHERE status='待处理' |
| 近30天趋势 | 折线图 | 按日期分组计数 |
| 驾校排行 | 横向柱状图 | GROUP BY school_short |
| 投诉类型 | 饼图 | GROUP BY complaint_type |
| 处理状态 | 环形图 | GROUP BY handle_status |

### 飞书风格样式
- 圆角卡片：border-radius: 12px
- 柔和配色：#F5F7FA 背景，#3370FF 主色
- 阴影：box-shadow: 0 2px 8px rgba(0,0,0,0.08)
- 数字字体：大号粗体，颜色渐变
