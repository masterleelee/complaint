## 三、测试过程事件记录

1. **14:22 服务重启**：测试中途 Flask 服务重启一次（日志 `Running on http://127.0.0.1:5003`），导致当次请求 Failed to fetch。已作为环境事件记录，重试后流程正常；同时意外验证了 R01 网络错误态。
2. **并行数据变更**：QA-FEE-KM-001 在 13:08:04 被 Agent-B 的 API 测试 fee_confirm/fee_unlock 改写为 confirmed（operation_logs 可证）。列表徽章"✓ 费用已确认"与DB一致 → UI 展示正确；扣费1500/退2380 与预置明细吻合，反向印证退费计算无误。
3. **导航语义**：侧栏「学员信息」即工作台视图（view='workbench'），非独立学员页——初看像导航失效，实为命名歧义，登记 ISS-C-A02 (P2)。
