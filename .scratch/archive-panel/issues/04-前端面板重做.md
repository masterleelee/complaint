## 需求

现有面板（`templates/index.html:2588-2610`，21 行表格）是"退路"级别：只有文件名 + 大小 + 时间 + 下载链接。
要把它做成**主入口**：点开就有反应、能预览、失败说得清楚。

> ⚠️ **范围修正（用户 2026-09-10 原话）**：「不用这个 zip，用户需要哪个文件自己打开，
> 自己下载就行，不要压缩打包」。故本单**不含任何打包能力**：只有单文件下载 + 单文件预览。

## 改动点

### A. 状态与逻辑（`static/js/composables/useWorkbench.js`）

现状在 L538-587（`kjFiles*` 系列 + `openKjFiles` + `kjFileUrl` + `fmtKjSize`）。改造：

1. **重命名**去掉 `kj` 前缀（它来自已废弃的 kjfolder 概念），建议 `ap*`（archive panel）：
   `apOpen / apLoading / apFiles / apDir / apError / apErrorCode / apLastTicketId / apLastName`
   → 同步更新 `useWorkbench.js:1054` 的 return、`static/js/app.js:292` 与 `:948` 两处解构注入、以及模板绑定。
2. `openArchive(t)`（L589-620）**重写**：不再 `fetch('/open-archive')`、不再 blur 猜测，直接设置 `apLastTicketId` 并调 `openArchivePanel()`。
3. 新增方法：`apDownloadUrl(name)`（复用现有 `kjFileUrl`）、`apPreviewUrl(name)`、`apCanPreview(name)`、`apCopyPath()`、`apRefresh()`、`apToggleView()`。
   ⚠️ **无 `apZipUrl()`** —— ZIP 已作废。
4. **删除死变量 `kjFilesDir`**（赋值于 L564，全项目无人引用——`audit.md` §1.3 已确证）。

### B. 模板（`templates/index.html`）

重做 L2588-2610 的面板：
- 头部：`归档文件` + 学员姓名 + 案件日期 + 关闭按钮
- 工具栏：`复制路径` / `刷新` / `列表↔图标` 切换（**无打包**）
- 文件行：类型图标（docx/pdf/txt/img 分色）、文件名、大小、修改时间、`下载`、`预览`（不可预览的类型置灰并加 title 说明）
- 三态渲染（**必须按后端已冻结的契约渲染，用 `code` 而不是猜文案**）：
  - `apLoading` → 加载中
  - `apErrorCode === 'dir_missing'` → 直接展示后端 `message`：「案件归档夹不存在：该学员尚未生成投诉登记表/回复函，请先在工单里生成后再查看」
  - `apErrorCode === 'root_unavailable'` → 直接展示后端 `message`：「归档根目录不可用：共享盘可能未挂载或当前路径无权限，请联系管理员，或稍后重试」
  - 其他失败 → 通用文案 + `errors` 明细；技术细节在 `detail` 里，**默认折叠、不主动展示**
  每类错误给**该做什么**的指引，不要只报错。
- 底部：`共 N 个文件 · 合计 X MB`

### C. 样式（`templates/index.html` 内联 `<style>`，紧随 L597-598 的 `.row-open` 区块）

新增面板专用类（`.ap-*`）。`static/css/style.css` 现已在 D0 提交中回到干净状态，
但本单面板样式仍就近放内联 `<style>`（与既有 `.row-open` / `.batch-bar` 同处），
避免触碰全局样式表引发无关回归。
