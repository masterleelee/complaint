# ISS-AP-04 · 前端：归档面板重做（提升为主路径）

**Status:** pending（等 01/02/03 契约冻结）
**Priority:** P1（本单是方案 A 的主体）
**依赖:** ISS-AP-01 / 02 / 03
**并行:** ❌ 不可与后端并行——必须先冻结接口契约，否则反复返工

## 需求

现有面板（`templates/index.html:2588-2610`，21 行表格）是"退路"级别：只有文件名 + 大小 + 时间 + 下载链接。
要把它做成**主入口**：点开就有反应、能打包、能预览、失败说得清楚。

## 改动点

### A. 状态与逻辑（`static/js/composables/useWorkbench.js`）

现状在 L538-587（`kjFiles*` 系列 + `openKjFiles` + `kjFileUrl` + `fmtKjSize`）。改造：

1. **重命名**去掉 `kj` 前缀（它来自已废弃的 kjfolder 概念），建议 `ap*`（archive panel）：
   `apOpen / apLoading / apFiles / apDir / apError / apErrorCode / apLastTicketId / apLastName`
   → 同步更新 `useWorkbench.js:1054` 的 return、`static/js/app.js:292` 与 `:948` 两处解构注入、以及模板绑定。
2. `openArchive(t)`（L589-620）**重写**：不再 `fetch('/open-archive')`、不再 blur 猜测，直接设置 `apLastTicketId` 并调 `openArchivePanel()`。
3. 新增方法：`apDownloadUrl(name)`（复用现有 `kjFileUrl`）、`apZipUrl()`、`apPreviewUrl(name)`、`apCanPreview(name)`、`apCopyPath()`、`apRefresh()`、`apToggleView()`。
4. **删除死变量 `kjFilesDir`**（赋值于 L564，全项目无人引用——`audit.md` §1.3 已确证）。

### B. 模板（`templates/index.html`）

重做 L2588-2610 的面板：
- 头部：`归档文件` + 学员姓名 + 案件日期 + 关闭按钮
- 工具栏：`打包下载` / `复制路径` / `刷新` / `列表↔图标` 切换
- 文件行：类型图标（docx/pdf/txt/img 分色）、文件名、大小、修改时间、`下载`、`预览`（不可预览的类型置灰并加 title 说明）
- 三态渲染：
  - `apLoading` → 加载中
  - `apErrorCode==='dir_missing'` → 「该学员尚未生成投诉登记表 / 回复函，请先在工单里生成后再查看」
  - `apErrorCode==='root_unavailable'` → 「归档共享盘暂时不可用（可能未挂载），请联系管理员，或稍后重试」
  - 其他失败 → 通用文案 + `errors` 明细
  每类错误给**该做什么**的指引，不要只报错。
- 底部：`共 N 个文件 · 合计 X MB`

### C. 样式（`templates/index.html` 内联 `<style>`，紧随 L597-598 的 `.row-open` 区块）

新增面板专用类（`.ap-*`）。**不要**动 `static/css/style.css`（该文件已处于未提交修改状态，避免冲突叠加——见 audit.md §0 的 D0）。

## 验收标准

- [ ] 列表行点按钮 → 面板打开并列出文件，**不发起 `/open-archive` 请求**（用浏览器 Network 或 mock 断言）
- [ ] 4 个文件的下载、打包、PDF 预览按钮均可用
- [ ] docx 的「预览」按钮置灰且 title 说明原因
- [ ] 三态错误各能触发且文案正确（用 mock 接口返回不同 code 验证）
- [ ] 面板关闭后重新打开另一工单，数据不串（`apLastTicketId` 正确刷新）
- [ ] 列表↔图标视图切换正常
- [ ] 浏览器 E2E：`errors` 与 `console` 全空
- [ ] **不新增 ES module**（避免 importmap 白屏坑，见 AGENTS.md 雷区）

## 风险

- **中**：重命名 `kj*` → `ap*` 会同时触碰 `useWorkbench.js` / `app.js`（两处）/ `index.html` 四处，任一处漏改即白屏或属性未定义。**必须用 grep 全量核对**，改完立即跑 E2E。
- **低**：不需要 bump importmap（不新增模块），但 `useWorkbench.js?v=31` 与 `app.js?v=45` 必须 bump。
