## 改动内容

1. `tests/conftest.py` 新增 autouse fixture `_isolate_archive_root`：
   - 用 **wrap**（而非替换）真实 `config.load_config`，只覆盖 `archive_root` 一个键，
     其余配置段（`paths` / 三个系统 / 4 个 llm 段）保留真实值 → 不波及非归档用例；
   - 同时作用于两个「`from config import load_config` 直接绑定」点：
     `app` 与 `services.archive_service`；
   - 锚定到每例 `tmp_path`，故 `build_archive_dir(ticket, root=str(tmp_path))`
     这类既有断言口径不变；
   - 只处理已导入模块（不主动 import `app`），不打乱用例对导入时序的假设；
   - 用例自身的 monkeypatch 在 fixture 之后生效，仍可覆盖本隔离（既有 12 处
     `monkeypatch.setattr(app_module, "load_config", ...)` 全部保持原语义）。

2. `tests/test_archive_root_isolation.py`（新增，4 例）——把验收项变成可执行断言：
   - `test_both_modules_archive_root_isolated_to_tmp`：两个模块的归档根都 == 本用例 `tmp_path`；
   - `test_isolated_root_never_under_real_root`：隔离根不得落在真实归档根之下；
   - `test_legacy_config_module_patch_no_longer_leaks`：**复现原 bug 写法**
     （只 patch `config` 模块）不再导致 app 层读到真实归档根；
   - `test_other_config_keys_kept_real`：其余配置段未被打桩丢失。
